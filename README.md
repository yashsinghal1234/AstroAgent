# ✧ Aradhana AstroAgent

A premium, state-of-the-art cognitive spiritual companion and agentic AI astrologer. **AstroAgent** acts as a gentle, high-precision mirror for the soul, allowing seekers to cast mathematically-correct birth charts, correlate transits, and explore their cosmic blueprint with deep psychological and spiritual warmth.

Built as a stateful multi-agent system, AstroAgent utilizes a **LangGraph** reasoning backend paired with a high-fidelity **React** web client. It calculates true planetary coordinates using real astronomical ephemerides (NASA JPL DE421 ephemeris)—completely eliminating LLM hallucination in astrological details.

## ✦ Advanced Core Features

### 🧠 Agentic Reasoning Backend (`backend/agent.py`)
* **Multi-Node State Graph**: Uses a compiled stateful LangGraph to govern conversational routing, coordinates extraction, chart rendering, and astrological guidance.
* **Granular SSE Stream Filtering**: Evaluates event metadata from `astro_agent.astream_events` to stream ONLY tokens generated by the final `expert` node. This filters out intent classifier LLM tokens, keeping the final chat stream completely clean.
* **Grounded RAG Tool (`knowledge_lookup`)**: Uses a keyword-matching knowledge base over standard definitions to keep LLM interpretations highly consistent, authentic, and accurate.
* **Strict Safety Guardrails**: Includes robust programmatic prompts that warmly decline off-topic, medical, legal, or stock market questions, directing seekers to certified professionals.

### 🪐 Interactive Astrolabe Natal Wheel (`frontend/src/App.jsx`)
* **Aspect Lines Grid**: Automatically calculates angular aspects between planets and draws delicate coordinate lines inside the inner wheel: harmonious **Trines** (120° in emerald-green), challenging **Squares** (90° in rose-red), tense **Oppositions** (180° in amber), and supportive **Sextiles** (60° in dashed sky-blue).
* **Conjunction Anti-Collision Stacking**: Sorts planetary coordinates and stacks conjunct bodies (within 8°) radially into concentric lanes, preventing any overlaps or illegible labels.
* **Central HUD Dashboard Dial**: Smoothly displays the planet's glyph (e.g. `♀`), name (`Venus`), zodiac coordinates (`Capricorn 12°34'`), and house placement directly inside the glassmorphic center on hovering over any planet dot.
* **High-Precision Chronometer Ticks**: Plots 72 micro-tick marks at 5-degree intervals around the outer boundary for a scientific, astrolabe-like instrument feel.
* **Spiritual Emojis & Symbols**: Employs authentic unicode planetary glyphs (`☉`, `☽`, `☿`, `♀`, `♂`, `♃`, `♄`, `☊`, `☋`) and zodiac sign icons (`♈`, `♉`, `♊`, etc.) to provide instant visual quality.

### 💬 ChatGPT-Style Chat Workspace
* **Animated Bouncing-Dots Indicator**: Displays three bouncing golden dots inside a glassmorphic chat bubble when the model is geocoding or computing degrees, assuring the user of progress.
* **Pulsing Text Cursor**: Appends a soft terminal typing block (`▋`) to the end of the text while active streaming is occurring.
* **Clean History**: Automatically removes active badges, step indicators, and intermediate logs from completed history cards, keeping the view clean.
* **High-Contrast Editorial Typography**: Renders forms, buttons, header, and logs in a clean system sans-serif font for maximum legibility, contrasting with elegant serif typography (`font-serif`) for the astrologer's readings.
* **Themed Celestial Scrollbars**: Thin, custom-designed, amber-glowing scrollbars configured globally to match the deep indigo dark mode.

1. **Natal Chart Casting & Alignment**: Input a seeker's date of birth, exact time, and location to immediately cast their natal chart using the JPL ephemeris. 
2. **Personalized Astrology Interpretations**: Explore sun signs, moon signs, ascendants, and exact placements across houses with a focus on self-reflection and psychological mindfulness.

## ✦ Installation & Local Setup

### 1. Backend Server Setup
Ensure Python 3.10+ is installed on your local machine.

```bash
# Navigate to project backend
cd backend

# Create your .env configuration file
# Google Gemini (Default):
echo GEMINI_API_KEY="your_api_key_here" > .env

# OR for Groq (generous free tier, highly recommended for instant responses!):
# echo GROQ_API_KEY="gsk_your_key_here" > .env

# Install backend dependencies
python -m pip install -r requirements.txt
# (Includes: langgraph, langchain-google-genai, skyfield, geopy, pytz, timezonefinder, fastapi, uvicorn, sse-starlette)

# Start the FastAPI server
python main.py
```
*The backend API will run locally on `http://localhost:8000`.*

### 2. Frontend React Client Setup
Ensure Node.js is installed on your local machine.

```bash
# Navigate to frontend folder
cd frontend

# Install node dependencies
npm install

# Start the local development server
npm run dev
```
*The frontend application will open locally on `http://localhost:5173`.*

## ✦ Technical Highlights & Design Notes

1. **NASA-Grade Astrometry Offline**: The astronomical calculations engine utilizes the `de421.bsp` ephemeris binary. This allows complete offline calculation of high-precision planetary coordinates (Aries 0° to Pisces 360°) within seconds.
2. **Whole-Sign House Division**: The project defaults to the traditional Whole-Sign house system—the foundation of Vedic and classical Western astrology—ensuring clean house segments.
3. **Offline Geocoding Fallback**: Geocoding utilizes the OpenStreetMap Nominatim API, with timezones determined by latitude and longitude lookup via `timezonefinder` to accurately determine birth chart charts regardless of daylight saving rules.
